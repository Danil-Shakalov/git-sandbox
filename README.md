## Тема проекта

Консольная программа на C++ для расчётов свободного падения:

- `fallSpeed(t)` — скорость падения через время `t`
- `fallHeight(t)` — высота падения за время `t`
- `fallTime(h)` — время падения с высоты `h`

Ускорение свободного падения: `g = 9.81 м/с²`.
